# 2026-10-27 TIL - 데이터 리터러시

## 데이터 → 정보 → 지식 → 지혜

댐 수위로 보면 이렇게 나뉜다.

- 데이터: 42.3m
- 정보: 수위 42.3m, 빠르게 상승 중, 기준까지 2.7m 남음
- 지식: 이 추세면 6시간 후 기준 초과 가능성 큼
- 지혜: 하류 안전을 고려해 단계적으로 방류하고 경보 발령

## 데이터 리터러시

데이터를 읽고, 이해하고, 해석해서 의사소통과 의사결정에 쓰는 능력. 네 가지로 나뉜다.

- 읽기: 숫자의 의미와 기준 이해 (수료율 80%가 신청자 기준인지 수강 시작 기준인지)
- 분석: 비교해서 패턴과 차이 찾기
- 활용: 분석 결과를 실제 행동으로 연결하고 효과도 데이터로 확인
- 소통: 사실, 해석, 제안을 구분해서 전달

## 분석 프로세스 (CRISP-DM)

비즈니스 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 배포

## 데이터 분류

- 변수 타입: 범주형(명목, 순서) / 수치형(이산, 연속)
- 구조: 정형(표) / 비정형(영상, 음성, 텍스트, 이미지)

## 통계 오류 사례

- 평균의 함정: 평균 연령이 37.3세여도 실제 고객은 20대 초반과 50대 초반에 몰려 있을 수 있음. 분포를 봐야 한다.
- 앤스컴 콰르텟: 평균, 표준편차, 상관계수, 회귀식이 전부 같아도 그래프는 완전히 다름. 시각화 필수.
- 심슨의 역설: 그룹별로는 B반이 높은데 전체로 합치면 A반이 높게 나옴. 그룹별 인원 비중이 달라서 생기는 일이다.
  - A반: 0.9×90% + 0.1×30% = 84%
  - B반: 0.2×95% + 0.8×40% = 51%

## 측정 수준

| 척도 | 예시 | 주의 |
|---|---|---|
| 명목 | 혈액형, 고객 ID | 순서 없음, 평균 무의미 |
| 서열 | 만족도, 등급 | 간격이 같다고 볼 수 없음 |
| 등간 | 섭씨 온도, 연도 | 0이 없음이 아니라서 배수 비교 불가 |
| 비율 | 매출액, 거리 | 배수 비교 가능 |

## 문제 정의와 지표

- "고객 데이터를 분석해 주세요"는 너무 막연함. 대상, 기간, 비교 기준, 후속 행동이 들어가야 분석 가능한 질문이 된다.
- 지표는 행동, 기간, 분모를 명확히 정의해야 한다. (DAU/WAU/MAU, 구매 전환율, 리텐션 등)
- 의사결정은 문제 정의 → 지표 설정 → 분석 → 해석 → 실행 → 검증의 순환이다.

## AI 시대

AI가 코드도 짜주고 요약도 해주지만 맥락, 데이터 편향, 상관과 인과 구분은 약하다. 쉬워질수록 결과를 검증하고 판단하는 능력이 더 중요해진다.

## 핵심 정리

- 데이터가 의미를 가지려면 맥락과 해석이 필요하다.
- 평균, 상관계수 같은 숫자만 믿지 말고 분포, 집단, 맥락을 같이 봐야 한다.
- 척도에 따라 쓸 수 있는 분석이 다르다.
- 좋은 분석은 좋은 질문(문제 정의)과 명확한 지표 정의에서 시작한다.
- AI를 쓰더라도 결과를 검증하고 책임지는 건 사람이다.
